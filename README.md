# Tangent Kyte Studio

The website for Tangent Kyte Studio, a software studio that designs, builds and runs web, mobile, AI and cloud software.

## Run it locally

The site is plain HTML, CSS and a little JavaScript, with no build step.

```bash
python -m http.server 8080
```

Then open http://localhost:8080.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole page: content, styles and script |
| `logo.svg` | Full logo |
| `logo-mark.svg` | Kite mark, also the SVG favicon |
| `favicon.ico` | Browser tab icon |
| `apple-touch-icon.png` | Home-screen icon for iPhone and iPad |

## Publishing

Any static host works, including GitHub Pages: in the repository settings, open **Pages** and deploy from the `main` branch, root folder.
