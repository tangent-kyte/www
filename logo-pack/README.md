# Tangent Kyte Studio logo pack

The mark is a kite in flight, split down its spine into navy and sky blue, with one straight string. The string is the tangent: a single line touching the shape.

All SVGs have their lettering converted to shapes, so they look the same on every computer without the font installed.

## What's inside

| Folder | Files | Use for |
| --- | --- | --- |
| `svg/` | `tangent-kyte-logo.svg` | Main logo on light backgrounds |
| | `tangent-kyte-logo-white.svg` | Main logo on dark or navy backgrounds |
| | `tangent-kyte-logo-stacked.svg`, `-stacked-white.svg` | Square-ish spaces: posters, slides, profile banners |
| | `tangent-kyte-mark.svg`, `-mark-white.svg` | The kite on its own, light or dark backgrounds |
| | `tangent-kyte-mark-navy.svg`, `-mark-mono-white.svg` | One-colour printing, stamps, embroidery |
| | `tangent-kyte-icon-navy.svg`, `-icon-light.svg` | Square app and social profile icons |
| `png/logo/` | 600, 1200 and 2400 px wide | Documents, email signatures, slides |
| `png/mark/` | 64 to 1024 px | Anywhere the SVG can't be used |
| `png/icon/` | 180, 192, 512, 1024 px | Apple touch icon, Android, LinkedIn, X, GitHub avatars |
| `favicon/` | `favicon.ico`, `favicon.svg`, 16/32/48 px, `apple-touch-icon.png` | Browser tabs and home-screen icons |

PNGs have transparent backgrounds, except the square icons.

## Typeface

Hanken Grotesk: Medium (500) for "Tangent Kyte", Regular (400) for "Studio". Free from Google Fonts.

## Simple rules

- Keep empty space around the logo at least as wide as the kite.
- Don't stretch, recolour, rotate or add effects to it.
- Below 24 px tall, use the mark on its own instead of the full logo.
